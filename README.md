# АСУО — Автоматизированная система учета оборудования
## Выполнил Корзун Владислав Сергеевич ЭФБО-01-24
> Рабочее название: **Invento**

Информационная система для учета, хранения, перемещения и обслуживания
оборудования в организации. Разрабатывается на языке **Python**.

---

## 📌 О проекте

Система предназначена для автоматизации процессов учета материально-технического
оборудования: от постановки на учет до списания. Заменяет бумажные журналы и
разрозненные Excel-файлы единой базой данных с удобным интерфейсом.

### Возможности (планируемые)

- ➕ Добавление, редактирование и удаление единиц оборудования
- 🔍 Поиск и фильтрация по категории, помещению, сотруднику, состоянию
- 🔄 Учет перемещений оборудования между отделами и помещениями
- 👤 Закрепление оборудования за материально ответственными лицами
- 🛠 Фиксация ремонтов и технического обслуживания
- 🗑 Списание оборудования с указанием причины
- 📊 Формирование отчетов и экспорт данных
- 🔐 Разграничение прав доступа по ролям

---

## 🎯 Цель проекта

Разработка информационной системы учета оборудования на языке Python
для повышения точности учета, сокращения времени инвентаризации и
обеспечения оперативного доступа к информации.
